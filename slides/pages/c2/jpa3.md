## TL;DR Jointures

| Relation | Côté propriétaire | Côté inverse | Clé étrangère |
| --- | --- | --- | --- |
| One-to-One | `@OneToOne` + `@JoinColumn` | `@OneToOne` + `mappedBy` | sur la table du propriétaire |
| One-to-Many / Many-to-One | `@ManyToOne` + `@JoinColumn` | `@OneToMany` + `mappedBy` | sur la table du côté many |
| Many-to-Many | `@ManyToMany` + `@JoinTable` | `@ManyToMany` + `mappedBy` | dans la table de jointure |

<br/>

`@JoinColumn` côté propriétaire, `mappedBy` côté inverse.

<br/>

Les slides suivantes donnent toutes les solutions finales, avec le SQL généré.

## One-to-One Uni-directionnel (clé étrangère sur User)

::left::

```kotlin {all|4|6-8}
@Entity
@Table(name = "users")
class UserEntity(
    @Id val email: String,
    val name: String,
    @OneToOne(cascade = [CascadeType.ALL])
    @JoinColumn(referencedColumnName = "email")
    val phone: PhoneEntity,
)

@Entity
@Table(name = "phone")
class PhoneEntity(
    // Doit être unique : @Id ou @Column(unique = true)
    @Id val email: String,
    val phoneNumber: String,
)
```

::right::

```sql {all|2,5,6|7,8}{at:'0'}
CREATE TABLE users (
 email varchar(255) NOT NULL,
 "name" varchar(255) NULL,
 phone_email varchar(255) NULL,
 CONSTRAINT users_phone_email_key UNIQUE (phone_email),
 CONSTRAINT users_pkey PRIMARY KEY (email),
 CONSTRAINT fk1qj2mfat2o9nn5mp097e50otl 
    FOREIGN KEY (phone_email) REFERENCES phone(email)
);

CREATE TABLE phone (
 email varchar(255) NOT NULL,
 phone_number varchar(255) NULL,
 CONSTRAINT phone_pkey PRIMARY KEY (email)
);
```

<!--
La clé étrangère est sur la table users, pointant vers phone
Relation uni-directionnelle: User -> Phone

## One-to-One Uni-directionnel (clé étrangère sur Phone)

::left::

```kotlin {all|14-16}
@Entity
@Table(name = "users")
class UserEntity(
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)

)

@Entity
@Table(name = "phone")

    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
```

```kotlin {all|7-13}
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    val id: Long?,
    val name: String,
    @OneToOne
    @JoinTable(
        name = "user_phone",
        joinColumns = [JoinColumn(name = "user_id")],
        inverseJoinColumns = [JoinColumn(name = "phone_id")],
```

## Many-to-Many (User <-> Groups)

```kotlin {all|7-13,21-22}
@Entity
@Table(name = "users")
class UserEntity(
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    val id: Long?,
    val name: String,
    @ManyToMany(cascade = [CascadeType.ALL])
    @JoinTable(
        name = "user_group",
        joinColumns = [JoinColumn(name = "user_id")],
        inverseJoinColumns = [JoinColumn(name = "group_id")],
    )
    val groups: MutableList<GroupEntity> = mutableListOf(),

@Entity
@Table(name = "groups")

    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
```

## One-to-Many explicite avec @JoinColumn

::left::

```kotlin

    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
```
